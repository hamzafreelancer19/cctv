# Glossary

| Term | Definition |
|------|------------|
| Control Plane | Central API, dashboard, reporting, and notification services |
| Edge | On-premise compute node performing stream ingestion and AI inference |
| Detection Event | Structured AI inference result persisted by the control plane |
| Alert | Operator-facing notification derived from one or more detection events |
| Tenant | Organization-scoped customer partition with isolated data access |
| Zone | Polygon region on a camera view used for rule evaluation |
| Edge Device | Registered on-premise worker authenticated via API key |
| Review Queue | Human verification workflow for AI detections |
| Evidence Clip | Short video or image artifact linked to an alert |
| Model Version | Immutable identifier for deployed inference model weights |
| RBAC | Role-based access control across Owner, Admin, Operator, Viewer |
| Hybrid Deployment | Edge inference on customer premises with centralized management |
| Idempotency Key | Client-supplied identifier preventing duplicate event ingestion |
| Retention Policy | Time-bound storage rules for metadata and evidence |
| Biometric Consent | Explicit approval required before face enrollment |
| PWA | Progressive Web App providing installable mobile-friendly UI |
| SLO | Service level objective for availability or latency |
| RTO/RPO | Recovery time/point objectives for disaster recovery |
